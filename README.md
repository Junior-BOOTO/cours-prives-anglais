# Progressions d’anglais pour cours particuliers

Programmes de progression en anglais conçus par **Junior BOOTO WABA**, organisés selon les niveaux du Cadre européen commun de référence pour les langues (CECR). Ils servent de trames adaptables pour des cours particuliers.

| Niveau | Objectif général | Programme |
| --- | --- | --- |
| A1 | Échanges simples et vocabulaire familier | [Programme A1](English_CEFR_Curriculum_A1.pdf) |
| A2 | Autonomie dans les situations courantes | [Programme A2](English_CEFR_Curriculum_A2.pdf) |
| B1 | Expression suivie sur des sujets familiers | [Programme B1](English_CEFR_Curriculum_B1.pdf) |
| B2 | Interaction fluide et argumentation | [Programme B2](English_CEFR_Curriculum_B2.pdf) |
| C1 | Communication précise et nuancée | [Programme C1](English_CEFR_Curriculum_C1.pdf) |

Chaque PDF détaille des objectifs, unités, contenus linguistiques, activités et modalités d’évaluation. Le rythme et les activités peuvent être adaptés au diagnostic et aux besoins de l’apprenant.

Voir aussi les [progressions FLE](https://github.com/Junior-BOOTO/cours-prives-fle).
